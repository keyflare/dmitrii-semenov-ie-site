# Tear-Off Poster 404 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the ambiguous three-plate 404 interaction with a single obvious tear-off poster
gesture while preserving static content, working exits, accessibility, and the Keyflare Studio
visual language.

**Architecture:** A focused pure-logic module maps horizontal pointer movement to normalized tear
progress. `TearOff404Artwork` owns progress, pointer capture, click/keyboard activation, and reset;
`NotFoundPage` owns only the open/closed copy state. CSS renders a fixed blue result layer under a
warm clipped error sheet whose jagged boundary and handle share one progress variable.

**Tech Stack:** React 19, TypeScript, CSS Modules, React Router, Vitest, JSDOM

---

- [ ] **Step 3: Implement the progress helper**

Create:

```ts
export const TEAR_START_PROGRESS = 0.08;
export const TEAR_COMPLETION_THRESHOLD = 0.58;

type TearProgressInput = {
  startProgress: number;
  startClientX: number;
  currentClientX: number;
  artworkWidth: number;
};

export function clampTearProgress(progress: number): number {
  return Math.max(0, Math.min(1, progress));
}

export function getTearProgress({
  startProgress,
  startClientX,
  currentClientX,
  artworkWidth,
}: TearProgressInput): number {
  if (artworkWidth <= 0) {
    return clampTearProgress(startProgress);
  }

  return clampTearProgress(startProgress + (currentClientX - startClientX) / artworkWidth);
}

export function shouldCompleteTear(progress: number): boolean {
  return progress >= TEAR_COMPLETION_THRESHOLD;
}
```

- [ ] **Step 3: Implement `TearOff404Artwork`**

Implement a forwarded ref with this public contract:

```ts
export type TearOff404ArtworkHandle = {
  reset(): void;
};

type TearOff404ArtworkProps = {
  onOpenChange(open: boolean): void;
};
```

Use state and refs for `progress`, `dragging`, `open`, and the active pointer. Set
`--tear-position` to `${progress * 100}%`. The pull button must:

- capture the pointer on pointer down;
- use `getTearProgress()` during pointer move;
- call the open transition at the completion threshold;
- return to `TEAR_START_PROGRESS` below it;
- suppress the synthetic click after a real drag;
- use an ordinary click for mouse click, Enter, and Space activation.

Render these decorative layers with `aria-hidden="true"`:
